# Practicum_projects


## О репозитории


Репозиторий содержит два аналитических проекта: «Афиша» и «Секреты Темнолесья». Каждый проект размещён в отдельной папке и включает документацию и файлы с кодом для решения своей задачи.


## Структура репозитория и содержимое папок


### Папка `project-1-afisha` — проект по анализу данных сервиса «Афиша»


**Цель проекта:** выявить закономерности в поведении пользователей и факторы, влияющие на продажи билетов в сервисе Яндекс Афиша.


**В папке находятся:**
* `README.md` — описание проекта: цели, задачи, стек технологий, инструкция по запуску, ключевые выводы и рекомендации, а также ссылка на интерактивный дашборд в Yandex DataLens;
* `afisha-analysis.ipynb` — Jupyter Notebook с кодом анализа данных, визуализацией результатов и пошаговыми комментариями к этапам работы;


### Папка `project-2-secrets_darkwood` — проект по исследованию внутриигровой экономики игры «Секреты Темнолесья»


**Цель проекта:** оценить долю платящих игроков, проанализировать структуру покупок внутриигровой валюты «райские лепестки» и эпических предметов, проверить гипотезу о балансе сложности прохождения для разных игровых рас.


**В папке находятся:**
* `README.md` — описание проекта: цели, задачи, используемые технологии, инструкция по развёртыванию, ключевые выводы, рекомендации;
* `secrets_darkwood.sql` — SQL‑запросы для извлечения, агрегации и анализа данных из базы данных игры (PostgreSQL);

---


## Стек технологий
* **Проект 1 («Афиша»):** Python 3.8+, pandas, matplotlib, seaborn, scipy, Jupyter Notebook, Yandex DataLens.
* **Проект 2 («Секреты Темнолесья»):** SQL (PostgreSQL), DBeaver.
