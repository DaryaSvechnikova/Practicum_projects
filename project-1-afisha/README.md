## О проекте

Проект решает задачу комплексной оценки бизнес‑эффективности сервиса Яндекс Афиша: выявляет драйверы выручки, сезонные тренды и ключевые сегменты пользователей, чтобы сформировать обоснованные рекомендации по развитию продукта.


В основе исследования — анализ данных о заказах билетов, мероприятиях и курсах валют за период 01.06.2024–31.10.2024. Данные включают информацию о типах устройств, возрастных ограничениях, регионах и площадках проведения мероприятий.


Результаты представлены в двух форматах:
* **Jupyter Notebook** — полный цикл исследовательского анализа: загрузка и предобработка данных, проверка статистических гипотез (в том числе тест Манна‑Уитни), построение визуализаций.
* **Дашборд в Yandex DataLens** — интерактивная панель для мониторинга ключевых метрик, сегментации и отслеживания динамики.

**Стек технологий и библиотеки:** Python 3.8+, pandas, matplotlib, seaborn, scipy, Yandex DataLens.


## Ключевые выводы
* **Рост активности:** выручка и количество заказов демонстрируют положительную динамику с июня по октябрь. Пик выручки — **12,2 млн руб.** на неделе 21.10.2024.
* **Мобильные устройства:** **79,3 %** выручки (**124,6 млн руб.**) приходится на заказы с мобильных устройств, **20,3 %** (**31,9 млн руб.**) — с десктопов.
* **Структура выручки:**
   * концерты обеспечивают **56,5 %** выручки (**88,7 млн руб.**);
   * театр — **23,6 %** (**37,1 млн руб.**).
* **Региональная активность:** основной вклад в выручку дают:
   * Каменевский регион (**61,7 млн руб.**);
   * Североярская область (**25,5 млн руб.**).
* **Типы событий:** выручка формируется как за счёт объёма заказов (массовые события), так и за счёт высокой цены билета (премиум‑площадки).

## Инструкция по запуску

### Системные требования
* Python версии 3.8 или выше;
* установленные зависимости (см. `requirements.txt`).


### Порядок запуска
1. Клонируйте репозиторий:
   ```bash
   git clone <ссылка_на_репозиторий>
   cd <название_папки_проекта>
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Откройте файл `project-1-afisha-analysis.ipynb` и выполните все ячейки последовательно.
5. Перейдите по ссылке на дашборд для интерактивной аналитики.
